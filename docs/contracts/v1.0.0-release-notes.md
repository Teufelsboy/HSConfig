# HSConfig v1.0.0 Release Notes

[Back to the operator guide](../operator/README.md)

HSConfig v1.0.0 provides the supported Windows pre-run path for producing a
guide-aligned HearthRanger VisionAI `CustomConfig` package from a deck name and
deck code.

## Included

- One normal `hsconfig configure` workflow with immutable revision output.
- Strict `GlobalValues.json`, `Mulligan.json`, per-card CardID, and conditional
  `Combo.json` contracts.
- Source-to-runtime traceability with explicit evidence dispositions.
- One operator verdict in `reports/operator_summary.json`.
- Explicit guarded apply with transactional runtime replacement.
- Reproducible repository, package, distribution, security, and publishability
  verification for the v1.0.0 source tree.

## Boundary

This release is pre-run only. It does not claim replay analysis, runtime
sampling, patch correctness, gameplay improvement, or automatic post-game
tuning. Those outcomes remain `OUT_OF_SCOPE_ASSUMED_EXTERNAL`.
