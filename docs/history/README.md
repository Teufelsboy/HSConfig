# Historical Documentation

The active operator truth is linked from
[`docs/operator/README.md`](../operator/README.md). Start there for current
commands, report order, validation, and runtime-write boundaries.

Plans, specifications, research, reviews, and completed task reports are
historical evidence unless a current operator document explicitly marks them
active. Historical files explain decisions; they are not operator
instructions or apply authority.

Moving tracked historical material into this area must preserve Git history
and belongs in a dedicated cleanup task with its own review. No broad archive
move is part of routine maintenance.
